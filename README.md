# 🚀 CareerPulse: Career Intelligence Tracker

CareerPulse is a production-grade backend system designed to automate the job search lifecycle. It moves beyond simple tracking by integrating real-time API data and secure persistence.

## 🛠️ Tech Stack & Concepts
* **Language:** Python 3.12+
* **Concurrency:** Asyncio for high-performance API fetching
* **Database:** Relational SQLite for complex career data modeling
* **Reliability:** Unit testing with `pytest`
* **Architecture:** Clean, modular OOP design

## 📁 Project Structure
* `src/`: Core logic modules (Shortener, API Client, Database)
* `data/`: Local SQLite storage (Git-ignored for security)
* `tests/`: Automated test suite
* `requirements.txt`: Project dependencies
